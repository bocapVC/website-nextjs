# website-nextjs

BOCAP's marketing site, rebuilt in Next.js. Design tokens are ported 1:1 from
the legacy site's `src/styles.css` — see the design-system reference doc for
the full color/typography/spacing catalog and provenance notes.

## Getting started

```bash
pnpm install
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000).
